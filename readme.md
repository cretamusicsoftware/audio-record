# 🎙️ Audio Recorder

A simple **browser-based audio recorder** built with **HTML, CSS, and JavaScript** using the **MediaRecorder API**.

## Features

- Record audio from microphone
- Playback recorded audio
- Download recordings as a file
- Clean, modern UI

## Tech

- HTML
- CSS
- JavaScript
- MediaRecorder API

## Purpose

Built to learn **microphone access**, **audio recording**, and **Blob-based playback** in the browser.
